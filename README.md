# Greenhaven

Public porch site for Greenhaven: a 2D MMORPG.

Live pages: home, how to play, the world.

Downloads: Windows release on Dropbox (https://www.dropbox.com/scl/fi/5wnbg2ie49hfur2c7x07w/GreenhavenSetup.exe?rlkey=voe5gilo3is6j5h95es1tyhab&st=x2enkdfn&dl=0), Linux `downloads/greenhaven-linux`.

The native client is not this site.

Media in `assets/` (gameplay GIF, walk sprite, Happy Yak mascot) comes from the game project.
