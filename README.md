# Greenhaven

A native 2D MMORPG built with Rust and Bevy. One shared meadow, real skill ladders, and a character that stays.

**Website:** <https://otterdays.github.io/Greenhaven/>

## The game

- **Chop, mine, dig** — nine tree kinds, twelve rock kinds, sand and clay
- **Skill ladders to 99** — Woodcutting, Mining, Stride; every XP point saved
- **Sprint the trails** — hold Shift for 2x speed; fresh ground trains Stride
- **One shared meadow** — live chat, saved characters, villagers that talk back
- **First person, world map, skills sheet** — F5, M, P; F1 lists every key

## This repo

The native client is not this site. This repo holds the porch website: home, how to play, and the world pages.

Media in `assets/` (gameplay GIF, walk sprite, Happy Yak mascot) comes from the game project.
