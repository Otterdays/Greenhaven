Live pages: home, how to play, the world.

Downloads: Windows release on Google Drive (https://drive.google.com/file/d/1PjvRo1La3aveVYsZ2nTJfuOF-TC_tC--/view?usp=drive_link), Linux `downloads/greenhaven-linux`.
